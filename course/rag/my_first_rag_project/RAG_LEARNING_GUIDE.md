# RAG 学习通关指南：从零件到整车

本指南基于 `RAG_n.ipynb` 文件的内容，按照**“先骨架，后零件，再调优”**的逻辑重新组织。建议不要按 Cell 顺序死磕，而是按照以下四个阶段进行“跳跃式”学习。

---

## 阶段一：核心骨架 (Hello RAG)
**预计时间：2-3 小时**
**目标**：理解 RAG 的最简闭环，不纠结细节，只看数据是怎么流转的。

| Cell 范围 | 内容 | 学习建议 |
| :--- | :--- | :--- |
| **Cell 1-2** | 环境配置 (dotenv) | **[必修]** 必须弄清，这是所有项目的起点。 |
| **Cell 6** | TextLoader (最简加载) | **[核心]** 了解 `Document` 对象的 `page_content` 和 `metadata` 结构。 |
| **Cell 31** | TokenTextSplitter (基础切分) | **[核心]** 理解 `chunk_size` 和 `chunk_overlap` 的物理意义。 |
| **Cell 38** | OpenAIEmbeddings (基础向量) | **[核心]** 知道文字怎么变数组的，不需深究数学原理。 |
| **Cell 44-46** | **基础 RAG 链 (LCEL)** | **[重中之重]** 必须手敲一遍。理解 `|` 管道符如何把数据串起来。 |

---

**预计时间：3-4 小时**
**目标**：当你面对各种奇葩格式的数据时，回来查这部分“字典”。

| Cell 范围 | 内容 | 学习建议 |

## 阶段三：存储与检索优化 (Vector Stores & Retrievers)
**预计时间：3-4 小时**
**目标**：学习如何管理海量数据，并找得更准。

| Cell 范围 | 内容 | 学习建议 |
| :--- | :--- | :--- |

| **Cell 36** | 检索过滤器 (Filter) | **[重点研究]** 弄清“向量搜索 + 元数据过滤”的组合拳。 |

## 阶段四：高级进阶与评估 (Advanced RAG)
**预计时间：4-5 小时**
**目标**：解决真实场景下的复杂问题（如幻觉、追问、质量评估）。

## 💡 学习技巧：
1. **不要试图一次性跑通全文件**：因为 Cell 39 会删库，Cell 55 会依赖前面的变量。建议按上述阶段，每次专注于 3-5 个相关的 Cell。
2. **多打印结果**：在每个 Cell 后面加个 `print(len(docs))` 或 `print(docs[0].metadata)`，看清数据的流转过程。
3. **重点关注 Metadata**：你会发现贯穿全文的玄机都在 `metadata` 里，它是连接业务逻辑和 AI 检索的桥梁。
